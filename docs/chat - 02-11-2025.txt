Te explico sobre las URLs de despliegue y la autorización de Google OAuth:

¿Por qué cada despliegue genera una URL nueva?
Razón técnica: El sistema de despliegue crea instancias completamente independientes. Cada URL representa un despliegue único que:

Tiene su propio servidor
Su propia base de datos Supabase
Sus propios archivos de configuración
Su propio estado de sesiones
Ventajas del sistema actual:

✅ Aislamiento completo: Si algo falla, no afecta despliegues anteriores

✅ Desarrollo iterativo: Podemos hacer cambios sin "romper" la versión funcionando

✅ Rollback fácil: Siempre tenemos versiones anteriores funcionando

Desventajas:

❌ Nueva sesión OAuth: Cada URL requiere nueva autorización de Google

❌ URLs diferentes: No podemos mantener una URL fija para desarrollo

¿Se puede mantener la misma URL?
