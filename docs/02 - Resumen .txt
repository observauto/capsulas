Punto Actual del Trabajo (En qué paso estamos):
Problema Crítico Actual a Resolver:
A pesar de haber implementado el código para guardar las cápsulas completadas y las insignias en Supabase, los datos no se cargan ni se muestran correctamente en el dashboard del usuario.
Síntoma 1 (Resumen): La tarjeta "Cápsulas Completas" en la pestaña "Resumen" del dashboard siempre muestra "0", aunque el usuario haya completado cápsulas.
Síntoma 2 (Tab de Cápsulas): La pestaña "Cápsulas" siempre muestra el mensaje "No hay cápsulas completadas".
Síntoma 3 (Insignias): Las insignias ganadas (que se ven en el GamificationContext) no se cargan correctamente en el dashboard, apareciendo como "0" o perdiéndose entre sesiones.
Hipótesis del Problema:
Existe una condición de carrera (race condition). El UnificadoDashboard intenta cargar los datos (cápsulas, premios) y el GamificationContext intenta cargar las insignias antes de que la sesión del usuario esté completamente validada en el backend de Supabase. Como resultado, Supabase devuelve una lista vacía porque el usuario "aún no tiene permisos", y los componentes no reintentan la carga de datos una vez que la sesión está lista.
